1. OBJECTIVE
==================================================

Build the production-grade AI-IOS Alerting and Incident experience.

The experience must allow operators to:

- see active alerts
- understand severity
- identify affected assets/services
- investigate alert details
- acknowledge alerts where V1 supports it
- resolve/close alerts where V1 supports it
- filter and search alerts
- understand alert lifecycle
- inspect alert history
- correlate alerts with Monitoring
- navigate to affected resources
- manage alert-related workflows supported by V1

The UX must be:

- premium
- operationally focused
- information-dense
- highly scannable
- accessible
- responsive
- calm under high alert volume
- consistent with Monitoring
