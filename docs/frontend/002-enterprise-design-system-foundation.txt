==================================================
1. OBJECTIVE
==================================================

Create the production-grade Enterprise Design System foundation for AI-IOS.

The design system must provide one consistent visual language for the entire platform.

It must support:

- premium enterprise appearance
- high information density
- excellent readability
- accessibility
- light theme
- dark theme
- responsive behaviour
- reusable components
- data-heavy enterprise workflows
- future white-labeling
- future localization
- future feature expansion

The design system must be usable by every future frontend feature.

==================================================
3. DESIGN DIRECTION
==================================================

AI-IOS is an enterprise infrastructure and operations platform.

The visual language must communicate:

- reliability
- technical sophistication
- operational clarity
- trust
- precision
- enterprise maturity

The UI must feel premium without looking decorative.

Use the following design characteristics:

- clean typography
- strong hierarchy
- controlled information density
- restrained colour usage
- clear semantic states
- subtle depth
- consistent spacing
- purposeful borders
- subtle elevation
- minimal but meaningful motion

Avoid:

- excessive gradients
- excessive glassmorphism
- excessive shadows
- excessive rounded cards
- decorative animations
- excessive colours
- consumer-app visual patterns
- inconsistent spacing
- giant empty dashboard cards
- unnecessary visual noise

==================================================
4. DESIGN SYSTEM LAYERS
==================================================

Implement the design system in these layers:

Layer 1:
Primitive Tokens

Layer 2:
Semantic Tokens

Layer 3:
Component Tokens

Layer 4:
Reusable Components

Layer 5:
Feature UI Patterns

Do not mix these layers.
