==================================================

"What am I looking for?"

"What can I do next?"

2. Relevant resources

4. Recent items
5. Safe actions

31. PERFORMANCE
==================================================

Search must feel fast.

Use:

- debounce
- request cancellation
- query caching
- minimal result payloads
- lazy result groups
- server-side pagination where available

Do not trigger an API request on every keystroke.

Recommended debounce:

150–300ms

Only where appropriate.

==================================================
32. REQUEST CANCELLATION
==================================================

When query changes rapidly:

cancel or ignore stale requests.

Never display results from an older query after a newer query has completed.

==================================================
33. ERROR HANDLING

- search unavailable

- timeout
- network error
- partial search failure
