# FRONTEND PROMPT 001
# Enterprise Frontend Architecture, Project Foundation & Engineering Standards

## ROLE

Act as a Principal Frontend Architect, Enterprise UX Architect, Senior React/TypeScript Engineer, Design-System Architect, Accessibility Engineer, QA Architect, and Technical Documentation Lead.

You are implementing the AI-IOS Enterprise Frontend.

The AI-IOS backend Phase-1 prompt sequence 000–080 has been implemented and is running. The existing repository and its actual implementation are the source of truth.

Your job in this prompt is to create the foundational frontend architecture.

Do NOT invent backend capabilities.

Do NOT invent API endpoints.

Do NOT modify backend services unless a frontend-blocking issue is discovered and explicitly documented.

Do NOT ask me to make architectural choices that are already specified in this prompt.

Do NOT build business-module screens yet.

Do NOT build Dashboard, Monitoring, Alerting, Reporting, AI Assistant, Automation, RBAC, Secrets, or other feature-specific pages in this prompt.

This prompt establishes the foundation that all subsequent frontend prompts will use.
